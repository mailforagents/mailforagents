# Projects Root Agent Guide

This directory contains multiple project repositories plus a shared planning/context area.

Before taking action, read:
- `context/AGENTS.md`

Default behavior:
- You may read sibling project repositories to understand progress, recent work, and priorities.
- You may inspect git history, commit messages, changed files, and repo documentation.
- Do not modify files inside project repositories unless explicitly asked.
- By default, only write to files inside `context/`.

Rule precedence:
- If a sibling repo contains its own `AGENTS.md`, treat that as the local rulebook when working in that repo.
- If no local repo instructions exist, use `context/AGENTS.md` together with this root file.

Primary purpose:
- Maintain high-level business context
- Track priorities and real movement
- Draft status updates
- Help keep work aligned with current income priorities
